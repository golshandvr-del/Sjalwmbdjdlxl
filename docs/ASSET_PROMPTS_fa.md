# پرامپت‌های دقیقِ دارایی‌های تصویری برای AIِ طراح (فاز MC3/MC4)

> **هدفِ این سند:** بعضی چیزها را «کدزن نمی‌سازد» — آیکن‌ها، اسپرایت‌ها و
> انیمیشن‌ها گرافیک‌اند نه کد. این سند برای هر آیکن/انیمیشن یک **پرامپتِ دقیق**
> می‌دهد (فرمت، ابعادِ px، تعدادِ فریم، نام‌گذاری، محلِ قرارگیری) تا کاربر آن را
> به یک AIِ طراحِ تصویر بدهد و خروجی را در پروژه جایگزین کند.
>
> **اصلِ کار:** کد از قبل جای این دارایی‌ها را **داده‌محور** آماده کرده:
> - آیکن‌ها: `data/ui_icons/manifest.json` + `ui/shared/icon_service.gd`
>   (تا وقتی فایلِ واقعی نیامده، یک گلیفِ ساده‌ی برنامه‌ای نمایش داده می‌شود و بازی
>   نمی‌شکند). کافی است فایلِ PNG را در مسیرِ مانیفست بگذارید.
> - انیمیشن‌ها (MC4): فیلدهای اسپرایتِ mod در `tools/graphic_model.gd`.
>
> **قانونِ فنیِ مشترکِ همه‌ی دارایی‌ها:**
> - فرمت: **PNG، 32-بیت، با کانالِ آلفا (شفاف)**. (برای انیمیشن: sprite-sheet PNG.)
> - رنگ‌فضا: sRGB. بدونِ فرمتِ float/HDR (سازگاری با GL Compatibility، پرهیز از
>   هشدارِ RGBAFloat).
> - پس‌زمینه: کاملاً شفاف (نه سفید/سیاهِ توپُر).
> - مرکز: سوژه در مرکز، با حاشیه‌ی امنِ حدودِ ۱۰٪.
> - سبک: تخت/نیمه‌تخت، خطوطِ ضخیم و خوانا در اندازه‌ی کوچک؛ سازگار با تمِ تیره‌ی HUD.

## بخش ۱ — آیکن‌های رابطِ کاربری (MC3)

**محلِ قرارگیری:** فایل‌ها را در `assets/ui_icons/` بگذارید (همان مسیرِ مانیفست).
هر آیکن مربع و در اندازه‌ی مبنا **۱۲۸×۱۲۸ px** (قابلِ کوچک‌شدنِ خودکار توسطِ موتور).
نام‌گذاریِ فایل دقیقاً مطابقِ ستونِ «نامِ فایل» باشد.

| نامِ منطقی | نامِ فایل | توضیحِ تصویری برای پرامپت |
|-----------|-----------|----------------------------|
| select | `select.png` | یک نشانگرِ ماوس/کادرِ انتخابِ نقطه‌چین با یک مربعِ کوچک — مفهومِ «انتخابِ نیرو». |
| assign | `assign.png` | یک عددِ درونِ سپر/نشان (مثلاً «۱») — مفهومِ «تخصیصِ گروهِ کنترل». |
| move | `move.png` | یک فلشِ مستقیم رو به بالا-راست با یک نقطه‌ی مقصد — «حرکتِ مستقیم». |
| move_manual | `move_manual.png` | چند نقطه‌ی به‌هم‌وصل‌شده با خطِ شکسته (waypointها) — «مسیرِ دستی». |
| attack | `attack.png` | دو شمشیرِ ضربدری یا یک هدفِ نشانه‌گیری — «حمله». |
| stop | `stop.png` | یک مربع/هشتضلعیِ توپُر — «توقف». |
| zoom_in | `zoom_in.png` | ذره‌بین با علامتِ «+». |
| zoom_out | `zoom_out.png` | ذره‌بین با علامتِ «−». |
| settings_gear | `settings_gear.png` | یک چرخ‌دنده‌ی هشت‌دندانه — «تنظیمات». |
| pause | `pause.png` | دو میله‌ی عمودیِ موازی — «مکث». |
| play | `play.png` | یک مثلثِ رو به راست — «ادامه/شروع». |
| back | `back.png` | یک فلشِ رو به چپ یا فلشِ بازگشتِ منحنی — «بازگشت». |
| message | `message.png` | یک حبابِ گفتگو — «پیام/دیپلماسی». |
| build | `build.png` | یک چکش یا جرثقیل/داربست — «ساخت‌وساز». |
| minimap | `minimap.png` | یک مربعِ کوچک با چند نقطه — «مینی‌مپ». |
| undo | `undo.png` | فلشِ منحنیِ خلافِ عقربه — «واگرد». |
| redo | `redo.png` | فلشِ منحنیِ موافقِ عقربه — «ازنو». |

**پرامپتِ نمونه (برای یک آیکن):**
> "A flat, minimal game UI icon of a **gear/cog with eight teeth**, centered,
> thick clean outline, readable at small sizes, warm gold color on a fully
> transparent background, 128x128 px, PNG 32-bit with alpha, sRGB, no drop
> shadow, no background fill."

نامِ فایلِ خروجی را به `settings_gear.png` تغییر دهید و در `assets/ui_icons/`
بگذارید. برای هر ردیفِ جدول همین قالب را با «توضیحِ تصویری» جایگزین کنید.

## بخش ۲ — اسپرایت‌های انیمیشن (MC4)

> این بخش پس از پیاده‌سازیِ فیلدهای mod در MC4 تکمیل می‌شود. ساختارِ کلی:
> اسپرایت‌شیتِ افقی، فریم‌های مساوی، پس‌زمینه‌ی شفاف.

### ۲.۱ اسپرایتِ پرتابه/شلیک (projectile)
- **کاربرد:** آبجکتی که هنگامِ شلیکِ نیرو از مبدأ به هدف پرتاب می‌شود.
- **فرمت:** یک PNGِ تکی (یک فریم) یا اسپرایت‌شیتِ کوتاه (۲–۴ فریم برای چرخش).
- **ابعاد:** ۳۲×۳۲ px برای هر فریم (پرتابه‌های کوچک) تا ۶۴×۶۴.
- **جهت:** پیش‌فرض رو به **راست** (کد آن را به‌سمتِ هدف می‌چرخاند).
- **نام‌گذاری:** `projectile_<modid>_<unitid>.png`.

### ۲.۲ اسپرایت‌شیتِ انفجار/دود (death/explosion)
- **کاربرد:** هنگامِ نابودیِ نیرو/ساختمان پخش می‌شود.
- **فرمت:** اسپرایت‌شیتِ **افقیِ** PNG با فریم‌های مساوی.
- **تعدادِ فریم:** ۶ تا ۱۲ فریم.
- **ابعاد فریم:** ۶۴×۶۴ px (نیرو) یا ۱۲۸×۱۲۸ px (ساختمان).
- **fps پخش:** ~۱۲ fps (کد این را می‌خواند/تنظیم می‌کند).
- **نام‌گذاری:** `explosion_<modid>_<unitid>.png` + متادیتای `frames`, `fps`, `frame_size`.

> **توجه:** تا وقتی این فایل‌ها نیامده، MC4 یک انیمیشنِ ساده‌ی **برنامه‌ای**
> (دایره/ذراتِ محوشونده) پخش می‌کند تا بازی کامل باشد.
